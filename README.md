# 10 Days to 20th May 💙

A soft and heartfelt birthday countdown website created as a devotional-style experience for a loved one.

The website contains:
- 10 interactive countdown cards
- Bible verses
- personal notes/prayers
- soft animations
- a cozy scrapbook-inspired design

## Features
- Mobile responsive
- Interactive expanding cards
- Smooth animations
- Glassmorphism UI
- Emotional devotional experience

## Built With
- Stitch AI
- React / Next.js
- Tailwind CSS
- Vercel

## Deployment
Hosted on Vercel.

## Purpose
To create a meaningful digital birthday experience that makes someone feel loved, encouraged, and celebrated.
